# Budget App v1.3.1 Complete GUI Foundation

Drop these files into:

```text
budget-app/apps/web/
```

Then run from the project root:

```bash
pnpm install
pnpm --filter @budget-app/web dev
```

Open:

```text
http://<docker-vm-ip>:5173
```

This package includes:
- Vite config
- TypeScript config
- React entry point
- React Router setup
- App shell
- Sidebar
- Topbar
- Zustand UI store
- Theme system
- Budget selector
- Dashboard placeholder
- Settings placeholder
- Responsive CSS with Money Matters / Liquid Budget inspired styling
