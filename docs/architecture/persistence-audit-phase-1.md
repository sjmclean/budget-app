# Persistence Architecture Audit

Generated by `pnpm audit:persistence`. The JSON companion supports automated freshness checks.

## Current topology

```text
React features
  ↓
BudgetPersistenceProvider
  ↓
Local database (authoritative)
  ├─ operation journal
  ├─ checkpoints
  ├─ conflicts
  └─ attachment content
       ↓
Replication engine
       ↓
Replication server
```

The browser-local-storage provider and shared-server runtime have been removed. Legacy browser budget data is available only through a one-way canonical snapshot reader during first-run migration.

## Architecture rules

1. The local database is the sole browser budget persistence runtime.
2. Loading feature code before a provider is configured is an error; there is no implicit fallback.
3. Legacy localStorage budget data may only cross the migration snapshot boundary.
4. Remote operations update local authority first, then publish a batched reactive change.
5. Attachment bytes travel through the independent hash-addressed blob channel.
