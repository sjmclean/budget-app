# v2.44.1 Actual Budget ZIP Explorer

This release moves the Actual Budget importer from extension-based recognition to real package inspection.

Actual Budget exports are ZIP packages with the shape:

```text
metadata.json
db.sqlite
```

The web app now reads the binary ZIP payload, extracts `metadata.json`, verifies that `db.sqlite` is present, and shows a package-level preview in the existing Budget Import / New Budget flow.

The release remains preview-only:

- No budget records are written.
- SQLite table-level reads are intentionally not implemented in the browser layer yet.
- Account, category, payee and transaction counts remain marked as pending until the Actual SQLite repository/mapper stage.

Next step: implement an Actual SQLite repository that reads the detected `db.sqlite` and maps it into the normalized budget import model.
