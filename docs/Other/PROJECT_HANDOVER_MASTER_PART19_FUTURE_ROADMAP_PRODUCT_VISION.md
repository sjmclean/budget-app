# PROJECT HANDOVER MASTER --- PART 19

# Future Roadmap & Product Vision

## Purpose

This document consolidates the long-term vision, architectural direction
and every major roadmap item identified during development.

------------------------------------------------------------------------

# Vision

Build a modern, local-first budgeting platform that combines the
financial correctness of YNAB with the flexibility of desktop software
and the portability of user-owned data.

Core values:

-   Trustworthy
-   Fast
-   Transparent
-   Extensible
-   Cross-platform

------------------------------------------------------------------------

# Guiding Principles

-   Financial correctness first
-   User ownership of data
-   Canonical internal model
-   Progressive disclosure
-   Stable architecture over rapid feature growth
